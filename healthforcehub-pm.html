🔥 Firebase Configuration
1
Go to console.firebase.google.com → Create a project (or open an existing one)
2
Click Firestore Database → Create database → Start in test mode (you can tighten rules later)
3
Click Authentication → Sign-in method → Enable Anonymous
4
Go to Project Settings (gear icon) → Your apps → Add app → Web → Register → copy the firebaseConfig object
5
Paste the full config JSON below and click Connect
Firestore Security Rules — paste these in Firebase Console → Firestore → Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
